# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 0.2.x | ✅ |
| 0.1.x | ✅ (bug fixes only) |

## Reporting a Vulnerability

This project runs **editor-only code**. It does not execute at runtime in your
builds, and it never uploads data anywhere — audits run entirely locally.

If you still find a security-relevant issue, please **do not open a public issue**.
Instead, report it privately to the maintainer:

- Open a private report via GitHub: **Security → Report a vulnerability**
- Or send an email to the maintainer account on GitHub (`hhhnnnk4`)

We aim to acknowledge reports within **48 hours** and will keep you updated on
the fix timeline. Thank you for helping keep the community safe.
